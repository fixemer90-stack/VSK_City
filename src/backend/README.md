# Backend

Место для будущего ASP.NET Core / C# решения. Проектов и solution-файла пока нет.

Логические модули из концепции: Ingestion, Game Engine, Map Generator, REST API/BFF.
Начальный подход — единая кодовая база без преждевременного дробления на сервисы.
PostgreSQL хранит состояние; Redis не должен требоваться для корректности.

При инициализации определить проекты, версии SDK, миграции и команды проверки.
