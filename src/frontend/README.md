# Мой город — frontend интерактивного питча

Исполняемое desktop SPA: **Angular 21.2.26 / TypeScript 5.9.3 / PixiJS 8.22.0**.
Это демонстрационный интерфейс синтетического мира, не корпоративный MVP.
Контракт: `docs/features/E01-pitch-prototype/FEATURE.md` в корне репозитория.

## Запуск

Из `src/frontend` с Node **22.22.2** и npm **10.9.7**:

```sh
npm ci
npm start
```

Открыть `http://localhost:5188`. Dev server слушает `0.0.0.0:5188`;
`/api/**` и `/health` проксируются на `http://localhost:5189`.
Для мира необходим настоящий backend с PostgreSQL и Redis. При его недоступности
приложение показывает ошибку и повтор загрузки, а не локальный фиктивный мир.
Не открывайте dev server в недоверенную сеть.

```sh
npm test          # node:test + tsx: геометрия, API-ошибки, повтор ключа, нейтральные подписи
npm run typecheck # Angular compiler, strict TypeScript и strict templates
npm run build     # production; результат dist/atlas/browser
```

Версии зафиксированы без `latest`, включая `package-lock.json`.
Проверенные npm engines Angular 21.2.26 допускают Node `^22.12.0`;
Angular build требует TypeScript `>=5.9 <6.0`, compiler-cli `>=5.9 <6.1`.
Поэтому выбран TypeScript 5.9.3, а не Angular 22 с несовместимым требованием Node.
Шрифт Manrope локально поставляется из `@fontsource-variable/manrope` 5.3.0
(лицензия находится в установленном пакете); внешних CDN и картографических API нет.

## Docker

Контекст **корень репозитория**, не текущий каталог:

```sh
docker build -f src/frontend/Dockerfile -t vsk-pitch-frontend .
```

Стадии: `node:22.22.2-alpine` → `nginx:1.28.3-alpine`, контейнерный порт 80.
`Dockerfile.dockerignore` исключает node_modules, кэши и остальные части репозитория.
Nginx проксирует `/api/` и `/health` в `http://backend:8080`; для этого требуется
Compose-сеть с сервисом `backend`. Неизвестные frontend-пути возвращают SPA.
Данные API не кешируются. Сам frontend не хранит состояние мира на диске.
Compose и backend находятся вне зоны ответственности этого каталога.

## Работа с атласом

- Начальная персона `TEST-AGENT-001-044`, сценарий «Город и парковки».
- Россия → выбор города → выбор улицы; «Моя улица» возвращает выбранного агента домой.
- Карта России — локальная векторная основа Natural Earth v5.1.2 и координаты 25 городов
  в единой конической проекции. Точки не сдвигаются ради подписей; основные названия видны
  сразу, остальные — при наведении и в списке. Это обзорная карта, не точная геодезия.
  Источники/ограничения: docs/pitch/GEODATA.md. Внешних картографических запросов нет.
- Городской обзор использует LOD; детальная улица рисует **каждый** дом и парковку.
  Расположение зависит только от серверного `lotIndex`, не от порядка ответов.
- Перетаскивание и колесо меняют вид. Кнопки масштаба, стрелки клавиатуры,
  `+`/`-` и `Home` доступны при фокусе на сцене. DOM-списки обеспечивают
  альтернативу canvas hit targets; на улице раскрывается список всех объектов.
- Демо-персона выбирается по сценарию и номеру, без скрытых имён владельцев.
  Это **не аутентификация**: переключение явно меняет запрашиваемый `agentId`.
- Директор — наблюдатель: личных действий и «Моей улицы» нет. Скрытые названия
  (`name: null`) не рисуются на карте и не заменяются вымышленными названиями.
  Настоящая защита имён находится на backend.
- Демо-кнопки всегда изменяют **выбранного агента**, даже если открыт чужой город.
  Ответ POST полностью заменяет состояние; frontend не рассчитывает начисления,
  уровни, распределение мотора, снос или время игры самостоятельно.
- Новый POST получает `crypto.randomUUID()`. Если исход запроса неизвестен,
  повтор сохраняет тот же `requestId`, а остальные действия и смена личности
  блокируются до подтверждения. Подтверждённая бизнес-ошибка показывается как ошибка.
  Ключ незавершённого запроса хранится только в текущей вкладке, не после reload.
- Сброс требует `confirm` и относится ко всему тестовому миру.
- Лёгкий GET раз в 6,5 секунды; при скрытой вкладке и неопределённом результате
  действия опрос приостанавливается. Таймер, observer и Pixi уничтожаются при teardown.
  Нет offline replay, постоянного animation loop или фальшивого роста в браузере.
- «Под снос» и срок берутся с сервера, даты явно показываются в МСК.
  Числа XP, ступеней, этажности и продаж не выводятся, рейтинга нет.

## Ограничения и проверка

Только desktop от 1100 px; меньшему окну показывается честное сообщение.
Целевые ширины 1280/1440/1600 px. Для сцены нужен WebGL; при отказе графики
остаются DOM-навигация и сообщение с повтором. Объекты используют 35 локальных PNG-спрайтов,
20 домов (10 ступеней A/B) взяты из пользовательской source/house, четыре парковки — source/parking.
Замена и экспорт — docs/pitch/SPRITES.md.
Сложной анимации нет; reduced motion учитывается.
Реальная корпоративная авторизация, источник договоров, Kafka, загрузки/S3
и production-интеграции здесь не реализованы.

Проверены 26 unit/component tests, typecheck и production build. Финальные проверки
повторены внутри Docker build-stage, чтобы исключить медленный WSL/NTFS bind-mount.
Pixi даёт неблокирующее предупреждение Angular о транзитивном CommonJS `@xmldom/xmldom`.
Настоящая браузерная интеграция выполнена общим S03 harness в `tests/pitch-browser`:
базовая приёмка E01 — 5 passed (продажи/снос, роли, 50 домов и рестарт).
После обновления правил/карты/спрайтов отдельно повторены 7 read-only сценариев: все 25 городов
открываются прямым кликом на минимальной desktop-ширине, карта вписывается на четырёх
ширинах, Москва и Владивосток имеют разные постоянные центры. Проверены 35 PNG,
прозрачность, хеши пользовательских SVG и реальные sprite instances. Скриншоты просмотрены;
отчёты — docs/reviews/E01-pitch-review.md, TEN-TIERS-review.md и PARKING-review.md в корне docs/reviews.
Клиентский cache guard учитывает rulesVersion, а A/B детерминирован по ID дома.
Это проверка синтетического питча, не корпоративная или production-приёмка.
