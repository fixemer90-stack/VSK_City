# Frontend

Место для будущего Angular + TypeScript + PixiJS приложения. Исполняемого проекта нет.

Планируемые зоны: корпоративная оболочка, профиль и навигация; сцены страны,
города, района и улицы; загрузка ресурсов и анимация изменений.
Расчёт продаж и фильтрация закрытых данных выполняются на backend.

При инициализации зафиксировать версии и lock-файл, команды запуска/сборки/тестов.
Не создавать фиктивные команды до появления реального проекта.
