# Frontend

Место для будущего Angular + TypeScript + PixiJS приложения. Исполняемого проекта нет.

Планируемые зоны: корпоративная оболочка, профиль и навигация; сцены страны,
города, района и улицы; загрузка ресурсов и обновление актуального состояния.
Расчёт продаж и фильтрация закрытых данных выполняются на backend.

Начальный объём — только desktop, минимализм и визуальное развитие.
Без числовых уровней/опыта, прогресс-баров, лидерборда, календаря и сложного replay анимаций.
Без права на имя владельца у улицы нет названия, даже нейтральной замены.
См. [правила](../../docs/GAME-RULES.md) и
[концепцию v0.4](../../docs/concept/Insurance_City_Concept_Architecture_v0.4.md).

При инициализации зафиксировать версии и lock-файл, команды запуска/сборки/тестов.
Не создавать фиктивные команды до появления реального проекта.
