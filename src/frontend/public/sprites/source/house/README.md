# Insurance City — Vector asset pack 02

- 10 SVG-файлов: уровни 9, 12, 14, 17, 25 этажей, варианты A/B.
- Все файлы содержат SVG path; встроенных PNG/JPEG и ссылок на внешние ресурсы нет.
- Прозрачный фон, изометрический ракурс; пригодны для загрузки как SVG-спрайты в PixiJS.
- Сохранены художественный стиль и силуэты последнего согласованного каталога.

## Важные ограничения

Это автоматическая векторная трассировка растрового художественного эскиза, не вручную созданные семантические этажи. Отдельные окна, фасады, крыши и этажи НЕ являются независимыми редактируемыми слоями. Этажность соответствует названиям концептов, но не гарантирована геометрически по каждому ряду окон. Для строгого соблюдения этажности и управляемой замены этажей нужна послойная ручная векторная переработка.
