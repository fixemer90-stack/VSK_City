# Тестирование

Автоматических тестов продукта пока нет. Модульные тесты будут размещаться
рядом с соответствующими frontend/backend проектами; здесь — межмодульные,
интеграционные и сквозные сценарии по мере появления реализации.

Приоритетные будущие проверки: стабильная связная планировка; отсутствие
пересечений зданий; повторная доставка и порядок событий; имущество/мотор/парковка;
аннулирования; серверная приватность; одинаковые снимки мира;
восстановление без Redis; ограниченная детализация обзора страны.
Тестовые данные — только вымышленные. Команды проверки пока не определены.
