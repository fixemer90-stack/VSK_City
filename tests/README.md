# Тестирование

Автоматических тестов продукта пока нет. Модульные тесты будут размещаться
рядом с соответствующими frontend/backend проектами; здесь — межмодульные,
интеграционные и сквозные сценарии по мере появления реализации.

Приоритетные будущие проверки: стабильная связная планировка; отсутствие
пересечений зданий; повторная доставка и порядок событий; имущество/мотор/парковка;
досрочные терминации; серверная приватность; одинаковые снимки мира;
восстановление без Redis; ограниченная детализация обзора страны.
Тестовые данные — только вымышленные. Команды продуктовых проверок пока не определены.

## Проверки генератора и входных данных

В `test_demo_data.py` есть исполняемые unittest-проверки: 20/25/30 городов,
50 агентов в каждом, уникальность договоров и АГД, связи справочников, корректность дат,
повторяемость файлов, полные снимки с изменением статусов, защита от неявной перезаписи
и совпадение готовых CSV с генератором. Python 3.11+, без сторонних зависимостей:

```sh
python3 -m unittest discover -s tests -p 'test_demo_data.py' -v
```

Готовые данные и ограничения: [data/demo](../data/demo/README.md).
Эти тесты не доказывают работу начисления опыта, приватности или таймера сноса:
продуктового движка и импортёра пока нет.

Будущие тесты должны опираться на разделы 12–13 [принятых правил](../docs/GAME-RULES.md):
накопительные пороги, сохранение опыта старых домов при появлении новых,
перенос парковочного вклада, снятие мотора сначала с парковки, перераспределение
опыта после сноса, сохранение старых улиц при переводе и отсутствие повторного зачёта.
Проверить также отсутствие названия в API без права на имя, сохранение улицы при блокировке,
повторное использование участка и отсутствие влияния обычного истечения срока.
Примеры в документации пока не являются выполненными продуктовыми тестами.

Для начального объёма проверить прямую связь город → улица и навигацию без района;
смена канала внутри города должна сохранять ID улицы, участки и накопленную застройку,
а новые продажи — продолжать её развивать. Перевод в другой филиал-город создаёт новую
улицу, не меняя место зачёта старых договоров. Канальные права на имена сохраняются
без отдельной игровой территории.
