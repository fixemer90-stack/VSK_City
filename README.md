# VSK City

Корпоративная игровая визуализация продаж страховых продуктов — Insurance City.
Компания представлена страной, филиалы — городами, каналы — районами, продавцы — улицами.
Один имущественный договор создаёт один дом; моторные договоры дают опыт для восьми
визуальных уровней. Избыток моторов отображается парковками.

## Текущий статус

Подготовлены организационный каркас, принятые игровые правила и концепция v0.4.
Приложение, зависимости, интеграции, сборка и CI ещё не реализованы.
Команд запуска приложения пока нет. Полное ТЗ и контракты интеграции не согласованы.

## Начать здесь

1. Прочитать [принятые игровые правила](docs/GAME-RULES.md) — актуальный источник формул и исключений.
2. Прочитать [концепцию v0.4](docs/concept/Insurance_City_Concept_Architecture_v0.4.md) — продукт и целевую архитектуру.
3. Проверить [дорожную карту](docs/ROADMAP.md) и [статус MVP](docs/MVP-STATUS.md).
4. До реализации уточнить открытые вопросы и оформить Feature/Story по [шаблонам](docs/templates/README.md).

[Версия v0.3](docs/concept/Insurance_City_Concept_Architecture_v0.3.md) сохранена без изменений
как исторический источник, а не действующий контракт.

Первая версия: desktop, минималистичный визуальный мир без числового прогресса,
лидерборда, просмотра прошлых дат и сложных анимаций. Агенты — игроки;
руководители — наблюдатели с раскрытием имён в пределах полномочий.

Целевой стек из концепции: Angular, TypeScript, PixiJS, ASP.NET Core/C#,
PostgreSQL, Kafka, Keycloak. Redis — кеш, необязательный для корректности.
Версии инструментов будут зафиксированы при создании исполняемых проектов.
