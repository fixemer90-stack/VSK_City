# VSK City

Корпоративная игровая визуализация продаж страховых продуктов — Insurance City.
Компания представлена страной, филиалы — городами, каналы — районами, продавцы — улицами.
Имущественные продажи создают дома, моторные определяют их развитие; мотор без имущества даёт парковку.

## Текущий статус

Подготовлен только организационный каркас репозитория. Приложение, зависимости,
интеграции, сборка и CI ещё не реализованы. Команд запуска приложения пока нет.
Концепция v0.3 — рабочий документ, а не согласованное ТЗ.

## Начать здесь

1. Прочитать [исходную концепцию](docs/concept/Insurance_City_Concept_Architecture_v0.3.md).
2. Проверить [дорожную карту](docs/ROADMAP.md) и [статус MVP](docs/MVP-STATUS.md).
3. До реализации согласовать требования и оформить Feature/Story по [шаблонам](docs/templates/README.md).

Целевой стек из концепции: Angular, TypeScript, PixiJS, ASP.NET Core/C#,
PostgreSQL, Kafka, Keycloak. Redis — кеш, необязательный для корректности.
Версии инструментов будут зафиксированы при создании исполняемых проектов.
