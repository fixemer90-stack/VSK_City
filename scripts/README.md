# Служебные команды

Каталог для будущих проверенных команд подготовки окружения, импорта вымышленных
данных и проверки проекта. Исполняемых скриптов пока нет.

Каждая команда должна документировать prerequisites, параметры и побочные эффекты.
Не добавлять заглушки, сообщающие об успешной сборке или тестах без их выполнения.
