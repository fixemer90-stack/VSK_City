# Графические ресурсы

Активные ресурсы находятся в src/frontend/public/sprites/: исходные SVG,
PNG для PixiJS, manifest.json с точками опоры и хешами, catalog.html.
Инструкция: [спрайты и замена графики](../docs/pitch/SPRITES.md).

Используются 10 визуальных ступеней домов (1, 3, 4, 5, 6, 9, 12, 14, 17, 25 этажей),
по два пользовательских варианта A/B на ступень. Всего 35 активных спрайтов:
20 домов, 4 парковки, 3 центра и 8 элементов среды. Предусмотрены дороги, свободные участки,
парковки на 10 мест с четырьмя состояниями (1–3, 4–6, 7–9, 10), необходимый декор
и постоянные landmarks с готовым окружением.
Сложные эффекты строительства/демонтажа, наградные арки и улучшения площади
не являются обязательным пакетом начальной версии.
Новые изображения проверять в реальной сцене: стиль, перспективу, сетку, footprint,
anchor, масштаб и слои. Оригиналы пользователя в source/house экспорт не изменяет;
source/new и source/old не являются текущим набором домов.

Для каждого стороннего ресурса фиксировать автора, источник и лицензию.
Крупные исходники добавлять только после решения об их хранении (например, Git LFS).
Не считать MIT репозитория разрешением на любые сторонние изображения.
