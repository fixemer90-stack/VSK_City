# Графические ресурсы

Графические ресурсы пока отсутствуют. Требования к художнику — раздел 12
[концепции](../docs/concept/Insurance_City_Concept_Architecture_v0.3.md).

Предусматриваются здания, дороги, парковки, декор, landmarks и эффекты.
Сначала согласовать стиль, перспективу, сетку, footprints, anchor и порядок слоёв;
затем проверить небольшую реальную сцену в PixiJS.

Для каждого стороннего ресурса фиксировать автора, источник и лицензию.
Крупные исходники добавлять только после решения об их хранении (например, Git LFS).
Не считать MIT репозитория разрешением на любые сторонние изображения.
