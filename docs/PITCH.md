# Как показать прототип VSK City

Статус: локальный стенд запущен, полный сценарий функционально проверен в Chromium
без подмены основного API. Ревью завершено, код и доказательства E01 опубликованы в main.
Результаты и исправления: [ревью](reviews/E01-pitch-review.md).
Карта и два уникальных центра: [свежая визуальная проверка](reviews/MAP-CENTERS-review.md).
Графика объектов: [23 спрайта и пользовательские дома](reviews/SPRITES-review.md),
каталог `http://localhost:5188/sprites/catalog.html`.

## Что показываем

Не отчёт о продажах, а общий мир, в котором результат агента становится видимым.
Существующие тестовые данные: 25 городов, по 50 агентов, 32 950 договоров.
Имена, номера АГД и договоры вымышлены. Демо-персона и роль — переключатели питча,
не корпоративная авторизация и не средство доступа к реальным данным.

## Локальный запуск

Нужны Docker Engine/Compose и свободные порты 5188/5189. Из корня репозитория:

```sh
docker compose -p vsk-pitch --env-file infra/pitch.env.example -f infra/pitch.compose.yaml up -d --build
```

Открыть `http://localhost:5188` в desktop-браузере с шириной от 1100 px.
Проверка зависимостей: `http://localhost:5189/health`.
PostgreSQL и Redis доступны только внутри изолированного проекта; чужие контейнеры
и БД команда не использует. Это локальный синтетический стенд, не публичное развёртывание.

Остановить без удаления данных:

```sh
docker compose -p vsk-pitch --env-file infra/pitch.env.example -f infra/pitch.compose.yaml stop
```

Не использовать `down -v` для обычной остановки: volumes содержат сохранённый демо-мир.
«Начать заново» в интерфейсе — отдельное подтверждаемое действие сброса только тестового мира.

## Короткий питч

1. «Перед нами не таблица KPI. Филиалы становятся городами, агенты — улицами».
   Открыть «Россия»: географический контур, Владивосток на месте и внутри кадра.
   Выбрать Москву — Кремлёвская площадь; затем Владивосток — Золотой мост над заливом.
   Оба центра постоянные, не зависят от продаж. После этого перейти на улицу.
2. «Общий силуэт складывается из отдельных вкладов». Нажать «Моя улица».
   Показать исходную высотку и парковки сценария «Город и парковки».
3. «Имущественная продажа создаёт дом». Нажать «Имущество» — появится новый дом;
   парковочный вклад перейдёт в его развитие. Старые дома не уменьшаются.
4. В выборе демо-персоны переключиться на «Чистый лист», открыть «Моя улица».
   Нажать «Имущество», затем несколько раз «Мотор»: при достижении порога дом меняет вид.
   Уровни и опыт считаются внутри, но не превращают сцену в цифровую панель показателей.
5. «Моторные продажи не пропадают и без домов». Выбрать «Автомобильный квартал»:
   видны парковки. Имущественная продажа превращает их вклад в развитие нового дома.
6. «Расторжение тоже отражается честно, без мгновенного исчезновения».
   На собственной улице с домом нажать «Расторгнуть имущество»: отметка «Под снос».
   Кнопка «+24 часа» ускоряет только демонстрационные часы; дом исчезает по сроку,
   моторный вклад сохраняется в оставшихся домах/парковках.
7. «Руководитель наблюдает, а не играет». Выбрать «Директор города»: личные продажи
   и «Моя улица» отключены, названия видны в своём городе. В другом городе персональные
   названия скрыты сервером, хотя застройка остаётся доступной.

Не обещать реальную интеграцию с продажами, рабочую корпоративную авторизацию,
готовый каталог графики или измеренную производственную нагрузку.
Кнопки питча создают синтетические изменения, а не страховые договоры в корпоративной системе.

## Ограничения прототипа

- Один синтетический мир для всех локальных демо-персон, не отдельные пользовательские песочницы.
- Для экономии PostgreSQL может хранить транзакционный JSON-снимок, не промышленную схему.
- Локальная обзорная географическая основа и 23 спрайта; восемь домов заменены пользовательскими изображениями.
- Уникальные центры пока есть только у Москвы и Владивостока; остальные используют общую площадь.
- Нет Kafka/Keycloak и реальных продуктов; демо нельзя выставлять в интернет как рабочий сервис.
- Нет файловых загрузок, поэтому S3/MinIO пока не подключён; соответствующее требование условное.
- Детали массового импорта, исправлений и переводов — следующий этап, не обещание этого питча.
