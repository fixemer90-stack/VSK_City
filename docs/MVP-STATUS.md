# Статус MVP

Локальный синтетический [питч E01](features/E01-pitch-prototype/FEATURE.md) работает;
полный browser/API сценарий выполнен. Это не завершение корпоративного MVP.
Финальное ревью и публикация E01 отслеживаются в [отчёте](reviews/E01-pitch-review.md).

| Область | Фактическое состояние |
| --- | --- |
| Frontend / PixiJS | Рабочие сцены страны/города/улицы, управление видом, demo-персона/роль и действия |
| Backend / расчёт | ASP.NET Core net10.0: имущество, 8 порогов XP, парковки, отложенный снос и идемпотентность |
| PostgreSQL / Redis | Реальное сохранение в JSONB под row-lock; восстанавливаемый Redis version-cache |
| Инфраструктура | Отдельные Docker-образы и Compose vsk-pitch, localhost5188/5189, собственные volumes |
| Вымышленные данные | 25 городов × 50 агентов, 32 950 договоров, воспроизводимый генератор |
| Проверки E01 | 17 C# assertions, 14 frontend, 10 HTTP/runtime, 5 Playwright, 5 Python fixture tests |
| Графика | Процедурная изометрия, схематическая Россия и общий тип civic landmark; не каталог художника |
| Настоящая авторизация | Нет Keycloak; demo-персона и роли не являются безопасной аутентификацией |
| Корпоративный источник / Kafka | Не подключены, реальный маппинг/порядок/исправления не согласованы |
| Production-готовность | Нет; one-row схема и localhost API предназначены только для синтетического питча |
| CI | Пока не настроен |

Проверены сохранение мира/срока после рестарта, конкурентный повтор, потеря Redis,
worker-снос без GET и серверное скрытие чужих имён. В браузере нет подмены основного API;
отдельный HTTP503 mock проверяет только ошибочное состояние интерфейса.

Полная приёмка [корпоративных требований](architecture/CORPORATE-REQUIREMENTS.md),
включая масштабирование нескольких реплик и файловый S3-поток при его появлении,
остаётся отдельной задачей. Обычное истечение/старые договоры/переводы и массовые
исправления требуют расширения универсального импортёра, а не одного успешного демо.
