# Статус MVP

Подготовлены шаблон структуры и документация; основные игровые решения приняты.
Продуктовая реализация отсутствует, продуктовые этапы не начаты.
Есть генератор и тесты вымышленных входных данных; это не игровой движок.
Актуальный объём упрощён: карта России → город → улица, без игровых районов;
канальные права руководителей сохраняются. Смена канала внутри города не создаёт новую улицу.

| Область | Фактическое состояние |
| --- | --- |
| Документация | Принятые правила, концепция v0.4, историческая v0.3, навигация, дорожная карта, шаблоны |
| Frontend / PixiJS | Нет исполняемого проекта |
| Backend / расчёт / генератор | Нет исполняемого проекта |
| API и Kafka-контракты | Не определены |
| PostgreSQL / миграции | Не реализованы |
| Keycloak / роли | Не реализованы |
| Ассеты | Каталог предусмотрен, графики нет |
| Инфраструктура / CI | Не реализованы |
| Автоматические тесты продукта | Отсутствуют |
| Вымышленные входные данные | 25 городов по 50 агентов, 32 950 договоров в двух снимках; генератор и 5 тестов |
| Корпоративные требования | Docker/env/stateless/PostgreSQL/Redis/S3 описаны в CR-01–CR-05; runtime не реализован |

Критерии приёмки из раздела 15 [концепции v0.4](concept/Insurance_City_Concept_Architecture_v0.4.md)
и примеры [правил](GAME-RULES.md) пока не подтверждены работающим движком.
Проверка документации не является продуктовым тестированием или runtime-проверкой.
Контракты источника, маппинг, календарная «дата 0» и измеримые нагрузки остаются открытыми.
Каркас не является работающим прототипом; CI пока не настроен.
Приёмка инфраструктуры ведётся по [корпоративным требованиям](architecture/CORPORATE-REQUIREMENTS.md),
а не по наличию документа или тестовых CSV.
