# S02 — Визуальное демо города

Статус: Готово для локального синтетического питча.

Контракт: [E01](FEATURE.md). Объём файлов: src/frontend/.

## Критерии приёмки

- [x] Angular/PixiJS собираются в production-артефакт с lockfile.
- [x] Работает карта страны → город → улица, городские улицы и «Моя улица».
- [x] Процедурные здания, дороги, парковки и постоянный городской центр создают цельную сцену.
- [x] Есть реальные действия через backend, обработка ошибок и явно помеченная демо-персона/роль.
- [x] Нет числовых XP/уровней, скрытые имена не подменяются подписью чужой улицы.
- [x] Детальная улица не агрегирует дома; смена версии не переносит здания по другим участкам.
- [x] Проверки/сборка исполнены; окончательный визуальный browser smoke относится к S03.

Статус изменяется только после фактического выполнения проверок.

Подтверждено: 14 frontend unit/component проверок, typecheck и production Docker build;
полный Chromium/API smoke, прямые клики по Pixi-карте и просмотр скриншотов.
Последний pointer-capture delta проверен родителем отдельной RED/GREEN регрессией и браузером.
