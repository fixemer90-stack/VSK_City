# Features и Stories

Продуктовые Features пока не созданы и не начаты.

Для каждой Feature создать `E01-<slug>/FEATURE.md`, а рядом — атомарные
`S01-<slug>.md`, `S02-<slug>.md` по [шаблонам](../templates/README.md).

- Одна Story — один проверяемый результат.
- До кода фиксируются границы, зависимости и критерии приёмки.
- Feature закрывается только после выполнения всех входящих Stories.
- Реализацию подтверждают команды и результаты проверок, а не наличие файлов.
- Статусы: «Не начато», «В процессе», «Готово», «Заблокировано».
- При закрытии обновлять Story, родительскую Feature и фактический статус MVP.
