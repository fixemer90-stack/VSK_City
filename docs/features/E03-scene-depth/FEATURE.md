# E03 — Корректная глубина изометрической сцены

Статус: В процессе.

## Дефект и границы

Центр города добавлялся после всех кварталов и всегда рисовался поверх них.
Сортировать кварталы целиком недостаточно: отдельные дома одного квартала могут быть
перед центром и за ним. Исправление только frontend, без изменений сохранённых данных,
продаж/XP/слотов, исходных SVG, PNG pack или масштаба центров.

Решение: нижний terrain, один общий object layer с сортировкой каждого спрайта по
проекции точки основания, верхние неинтерактивные annotations. Те же правила для улицы:
дома, парковки, зелень и декоративный центр. Сохранить native выбор улиц и pan/zoom.
Цель — естественные перекрытия, не полное отсутствие заслонения задних объектов.
Цельный спрайт центра сохраняется, пока реальные визуальные проверки не требуют разделения.

## Приёмка

- [x] TDD: исходная сцена проваливает регрессию порядка центр/foreground.
- [x] Центр имеет объекты до и после себя в общем sorted layer; высота картинки не меняет глубину.
- [x] Terrain/annotations не смешаны с object sorting; pending badges не блокируют выбор.
- [x] Москва, Владивосток и обычный центр проверены в реальном preview-браузере.
- [x] Zoom/pan, foreground native click и существующие сцены/спрайты не сломаны.
- [x] Полные frontend gates, независимое ревью, exact candidate и screenshots проверены.
- [x] Frontend-only rollout не меняет operator-world/другие сервисы; artwork WIP не включается и не откатывается.
- [ ] Код/документы опубликованы; все jobs реального Actions run текущего кода success.

Изолированные snapshots/tests и временные CI images не являются изменением operator-world.
Полный mutating suite допускается только disposable CI, не на рабочем vsk-pitch.
