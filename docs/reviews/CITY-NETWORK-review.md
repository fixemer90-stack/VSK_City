# CITY overview: связные извилистые дороги и непрерывная зелень

Дата: 8 ноября 2026. **Локальный кандидат, без rollout и push.**
Проверен отдельный frontend на `127.0.0.1:5388`; операторский frontend не заменялся.
Независимое ревью финального коммита остаётся за родительским агентом.

## Изменения и границы

- Вместо 50 отдельных прямых спрайтов дорог — детерминированный связный граф:
  волнообразные бульвары, закруглённая внешняя дорога, два коллектора возле центра
  и пешеходный подход к нему. Все 50 миниатюр имеют доступ к общей сети.
- Вместо бежевых промежутков и отдельных квадратных газонов — единая травяная
  плоскость с неброской текстурой, зелёным поясом и небольшими садовыми карманами.
  Светлый фон **за границей** изометрической карты остаётся фоном интерфейса.
- Сначала рисуются тротуары всего графа, затем асфальт всего графа: светлые
  торцевые швы на пересечениях устранены. Для обоих проходов воспроизводится
  одинаковая геометрия Pixi Graphics.
- Индексные позиции миниатюр, ID домов/улиц/участков и клики по объектам/земле
  сохранены. Продажи не меняют дорожную геометрию. Добавление 51-й улицы
  не сдвигает существующие адреса. Сады не занимают будущие миниатюры до 64-й.
- Детальная личная улица, карта России, три изображения центров, манифест и
  PNG/SVG не изменены. Все 98 файлов sprite-каталога замороженной сборки
  побайтно совпали с HEAD исходного `326de29`.
- Не менялись backend, данные, XP, сроки сноса, распределение вкладов и правила.
  Это обзорный визуальный слой, не транспортная симуляция и не новый генератор мира.

## Свежая проверка финальных исходников

Снимок: git archive исходного HEAD + только пять принадлежащих задаче code/test
файлов. Удаления пользовательских архивных SVG и посторонний parking ZIP
не включены в сборку и коммит. Зависимости взяты из кешированного build-stage;
сетевых установок и фиктивных ответов API не было.

В свежем контейнере `vsk-ci-city-network-build:1108`, `--network none`:

```sh
npm run lint && npm run typecheck && npm test && npm run build
```

Результат: lint и Angular typecheck успешны; **48/48 unit tests**; production build
успешен. Единственное предупреждение сборки — существующий CommonJS dependency
`@xmldom/xmldom` через Pixi WebWorkerAdapter, не ошибка.

Unit-регрессии проверяют компонент связности графа, доступ всех 50 улиц/центра,
кривизну, отсутствие пересечений с наземными footprint застройки/центра,
неизменность геометрии при заполнении/добавлении улицы/камере, защиту садов,
повтор stroke-path, depth и сохранение owner pointer handlers.

Chromium, настоящий backend; **18/18 browser cases**:

```sh
cd tests/pitch-browser
PITCH_BASE_URL=http://127.0.0.1:5388 \
PITCH_TEST_OUTPUT=../../test-results/city-network-resume \
npx playwright test city-network.spec.js depth.spec.js map-centers.spec.js \
  street-layout.spec.js sprites.spec.js parking.spec.js --grep-invert mutation
```

- Все 50 московских улиц открыты нативным `page.mouse.click` по доступной земле
  или объекту; проверен точный street ID и сохранённый набор house ID.
- Москва, Владивосток и общий центр: fit на **1100/1440/1920 × 960**, zoom,
  сохранённые позиции/арт миниатюр, ровно один центр, без горизонтального overflow.
- Существующие depth-order/zoom/pan/resize, карта (нативные клики по всем 25 городам),
  35 спрайтов, 4 парковки, личные улицы empty/motor_only/mixed/skyscraper/overflow/large
  прошли без изменений требований.
- Получено 79 PNG. Вручную просмотрены финальные fit 1100/1440/1920 и closeup:
  травяная поверхность непрерывна, дороги соединены, светлых швов на перекрёстках
  нет, центр остаётся читаемым. На fit 1100 миниатюры естественно мелкие;
  для деталей нужен штатный zoom. Сохранены приведённые ниже 11 снимков.

  после браузерной проверки одинаков:
