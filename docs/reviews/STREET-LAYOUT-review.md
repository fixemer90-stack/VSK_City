# Единая извилистая улица — визуальная проверка

Дата: 8 ноября 2026. Статус: кандидат проверен локально; операторский питч **не развёртывался**.

## Изменение

В детальном виде улицы вместо отдельных прямых дорог по рядам рисуется один
непрерывный открытый маршрут: плавно изогнутые отрезки и широкие полукруглые
развороты. Асфальт, тротуар и разметка проецируются из одной наземной плоскости.
Это не сетка с добавленными перпендикулярными соединителями.

Чистый helper `src/frontend/app/street-layout.ts` задаёт геометрию и размещение
участков по обе стороны дороги. Положение зависит только от `lotIndex`, а не от
числа домов или парковок. Продление добавляет хвост маршрута, не перемещая уже
размещённые объекты; повторное заполнение участка использует тот же адрес.
Минимальная пустая улица показывает 16 доступных участков и один разворот.

Изменена только визуальная проекция детальной улицы. ID, `lotIndex`, XP,
занятость, сроки сноса и backend не изменены. Исходные рисунки, масштаб,
внутренние якоря и выбор A/B по ID сохранены. Городская миниатюра и расположение
городских кварталов не менялись. Слои terrain / objects / annotations и глобальная
сортировка отдельных объектов по наземной глубине сохранены.

## Проверки

- TDD: сначала наблюдались падения на отсутствии единого маршрута, пересечении
  старых участков с новой дорогой и отсутствии единой Graphics-дороги; после
  реализации соответствующие проверки прошли.
- Дополнительная визуальная проверка обнаружила особенность Pixi: второй
  последовательный `stroke()` получает только конечную точку, если не повторить
  весь путь. Регрессия сначала воспроизведена тестом, затем исправлена повторным
  построением пути перед заливкой асфальта.
- `npm run lint`, `npm run typecheck`, `npm test`: **40/40** тестов прошли в
  network-isolated Docker build-образе финального кандидата.
- `npm run build`: production Angular build прошёл. Сохранилось предупреждение
  Pixi `@xmldom/xmldom` CommonJS optimization bailout, не ошибка сборки.
- Chromium: **14/14** read-only cases из `street-layout`, `depth`, `parking`,
  `ten-tiers`, `map-centers` прошли на финальном образе. Шесть сценариев улицы:
  пустая, моторная, смешанная, высотная, с переполнением, большая. Для них
  проверены ширины 1100 / 1440 / 1920, zoom, pan, fit, реальные дома и парковки,
  отсутствие горизонтального overflow, стабильные ID/якоря и сортировка глубины.
- Сохранены 58 PNG; вручную осмотрены смешанная улица, большой маршрут в приближении
  и парковки на минимальной desktop-ширине. На финальном PNG подтверждены пиксели
  и асфальта, и тротуара; полноэкранный fit большой улицы намеренно уменьшает дома,
  для деталей нужны штатные zoom/pan.

## Изоляция и воспроизведение

Проверялся отдельный временный frontend на loopback-порту 5388 с собственным
тегом образа. Его nginx запрещал все методы API, кроме GET/HEAD. Он читал
существующий синтетический backend; полный mutating suite намеренно не запускался.
В логах preview нет POST/PUT/PATCH/DELETE. Версия мира осталась 1960; `cities` и все
поля состояния, кроме естественно идущих часов `now`, совпали до и после проверки.
Все четыре операторских контейнера сохранили ID. Операторские reset, продажи,
перевод часов, rebuild и deployment не выполнялись.

Артефакты локальной проверки, включая логи и PNG:
`/mnt/d/My city/.hermes-scratch-street/` (`final-browser/`, `final-browser.log`,
`final-build.log`, `final-gates.log`, `preview-access.log`).
Это локальные доказательства, не опубликованный CI run и не rollout.

После создания безопасного read-only preview повторить только выбранные specs:

```sh
cd tests/pitch-browser
PITCH_BASE_URL=http://127.0.0.1:5388 \
PITCH_TEST_OUTPUT=../../test-results/street-layout \
npx playwright test street-layout.spec.js depth.spec.js parking.spec.js \
  ten-tiers.spec.js map-centers.spec.js
```

Не подменять эту команду полным `npm test` на операторском мире: остальные suites
могут изменять данные. Сборка сделана из снимка Git с наложением только изменённых
кодовых файлов; удалённые пользователем архивы SVG и неотслеживаемый ZIP парковок
не восстанавливались и в build context не включались.
