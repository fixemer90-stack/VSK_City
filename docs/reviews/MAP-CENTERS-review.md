# Карта России и два постоянных центра — проверка

Статус: реализовано и проверено на настоящем localhost-стенде vsk-pitch.
Это визуальное продолжение E01, не новая корпоративная приёмка.

## Результат

- [x] Ручной контур заменён локальной географической основой; контур и города используют одну проекцию.
- [x] Владивосток находится на полигоне Приморья; север ориентирован вверх.
- [x] Карта, все маркеры и основные подписи вписываются на 1100/1280/1440/1920 px.
- [x] Каждый из 25 городов открывается нативным canvas-кликом по своей точке на ширине 1100 px.
- [x] Проверено появление подписи Ярославля при наведении.
- [x] Москва: красная часовая башня/купола. Владивосток: вантовый мост/залив.
- [x] Остальные города имеют общий civic fallback; центры не зависят от продаж.
- [x] Production Docker build и Angular typecheck прошли; 20 frontend unit/component tests прошли.
- [x] 2 read-only Playwright сценария прошли; скриншоты отдельно просмотрены.
- [x] Windows host-facing localhost5188 вернул HTTP200.

## Найденная и исправленная регрессия

Независимое source-review новой карты нашло конкретный blocker: прямоугольник клика
Костромы перекрывал центр Ярославля. Родитель воспроизвёл RED в настоящем Chromium:
ожидался Ярославль, открывалась Кострома.

Исправление: круговые hit areas радиусом не более 49% расстояния до ближайшего города;
слой маркеров вынесен над подписями. Географические точки не раздвигаются.
После исправления повторный тест проходит для всех 25 городов, включая соседнюю пару.
Финальный delta принят родителем по коду и реальному browser regression;
первоначальное заключение passed=false не выдаётся за повторное независимое одобрение.

Модули центров отдельно проверены четырьмя тестами с настоящими Pixi Graphics:
разные трассы/границы, конечные координаты, детерминизм и изометрическое смещение.
Интеграция в городской renderer проверена браузером и скриншотами, не только названием caption.

## Сохранность мира и пределы проверки

Пересобран/recreate только frontend. Backend/PostgreSQL/Redis остались теми же контейнерами.
Сброс, восстановление старого снимка, продвижение времени и прямые записи в БД не выполнялись.
Оба новых браузерных сценария проверяют отсутствие исходящих POST.
За время работы мир изменился с version158 до version197; эти изменения не откатывались
ради совпадения с исходной проверкой. Snapshot является наблюдением на момент фиксации,
не обещанием неизменности мира при одновременной работе оператора.

Пять исходных сценариев E01 с продажами/рестартом в этой визуальной итерации не запускались,
чтобы не сбрасывать используемый мир. Их предыдущий PASS относится к базовой приёмке E01.
В старом browser-spec только обновлено вычисление координат native клика вместо старых пикселей.
CI по-прежнему не настроен. Историческая концепция v0.3 не менялась.
