# Внедрение 23 спрайтов и пользовательских домов

Статус: внедрено на живом localhost vsk-pitch. Функциональный код: bf437f8.
Набор содержит ровно 23 активных объекта: 8 домов, 4 парковки, 3 центра, 8 элементов среды.
SVG-мастеров в репозитории больше: старые дома сохранены, но активная спецификация
указывает на восемь пользовательских source/new/house_XX.svg.

## Приёмка

- [x] Новые восемь SVG прочитаны и отрисованы, оригиналы не изменены.
- [x] Поддержаны их размеры и встроенный PNG, индивидуальные точки опоры и масштабы.
- [x] Все восемь выходных PNG связаны SHA-256 с правильными пользовательскими исходниками.
- [x] Все 23 PNG реально декодируются; проверены сигнатуры, хеши и прозрачность.
- [x] Вместо процедурных домов/парковок/центров/растительности используются Pixi Sprite.
- [x] Все дома большой улицы представлены отдельными спрайтами, без ограничения числа договоров.
- [x] Сохраняются географическая карта и нативные клики по 25 городам.
- [x] Сохранены постоянные разные центры Москвы/Владивостока и общий fallback.
- [x] Production Docker build, Angular typecheck, 24 unit/component tests прошли.
- [x] Четыре read-only Playwright сценария прошли на настоящем API/frontend.
- [x] Каталог, улица, большая улица и городской обзор просмотрены по реальным скриншотам.
- [x] Доступ из Windows подтверждён: manifest содержит 23 записи и sourceFile нового дома.

Сначала наблюдался RED: существующий стенд не имел спрайтового manifest;
позже проверка пользовательских источников ожидала new/house_01.svg, но находила старый набор.
После интеграции оба условия GREEN. Экспорт новых SVG сначала был отвергнут старой политикой
запрета image; разрешён только ограниченный встроенный PNG, не внешние URL.

## Ревью

Независимое ревью адаптера SpritePack/scene и начального экспортёра: passed,
logic_errors=[] и security_concerns=[]. Оно подтвердило матрицу наземных тайлов,
пересчёт обрезанных anchors, загрузку и отсутствие бизнес-записей.
Последующее добавление sourceFile, смешанного pixelRatio и встроенного PNG выполнено
родителем под пользовательские файлы и проверено экспортом/хешами/браузером;
раннее заключение не выдаётся за ревью этих последующих строк.

Усилены прозрачность в browser-тесте, хеши реальных HTTP-файлов и точный allowlist ID/групп.
Остаются неблокирующие улучшения: общий depth-sort сцены, дополнительные тесты уничтожения
компонента при загрузке и отдельные негативные тесты всех вариантов декодирования PNG.
Исходные procedural Graphics-тесты центров относятся к сохранённому helper, не являются
доказательством внешнего вида новых PNG; его подтверждают каталог и скриншоты.

## Мир и границы проверки

Пересоздавался только frontend. Идентификаторы backend/PostgreSQL/Redis совпадают с исходными.
В этой итерации сброс/восстановление мира, продажи и продвижение времени не выполнялись.
Версия мира до/после наблюдения — 197; совпадение не обеспечивалось принудительным откатом.
Браузерные тесты спрайтов запрещают исходящие методы кроме GET/HEAD/OPTIONS.
Полный изменяющий мир E01 browser/API suite не запускался, чтобы не затронуть работу оператора.
CI по-прежнему не настроен. Правила начислений и историческая v0.3 не менялись.
