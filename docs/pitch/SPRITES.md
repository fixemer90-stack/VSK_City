# Набор спрайтов и замена графики

В игре используются 23 отдельных PNG с прозрачностью: 8 домов, 4 состояния парковок,
3 постоянных центра и 8 элементов окружения. Они переиспользуются между агентами.
Исходники и экспорт доступны в src/frontend/public/sprites/.
Каталог: `http://localhost:5188/sprites/catalog.html`.

## Активные дома пользователя

Все восемь домов подключены непосредственно из source/new/house_01.svg — house_08.svg.
Соответствие явное: new/house_01.svg → house-01.png → первая ступень, далее по номеру.
Оригиналы не переименованы и не перезаписаны. Старые house-01.svg — house-08.svg в корне
source оставлены как резерв и сейчас не используются для домов.

Размеры, sourceFile, точка опоры, pixelRatio и масштаб каждого объекта задаются в
scripts/sprite-spec.json. Для новых домов настроены индивидуальные параметры;
визуальная высота возрастает от первой до восьмой ступени, пороги игры не меняются.
Картинка иллюстративная: количество нарисованных этажей не подменяет данные модели.

В пользовательских SVG находится встроенное PNG-изображение. Это поддержано без внешних
HTTP-запросов; скрипты, обработчики событий и внешние изображения не допускаются.
Встроенный PNG ограничен по размеру, MIME и сигнатуре. Для него используется pixelRatio=1,
чтобы не увеличивать исходный растр искусственно; векторные остальные исходники экспортируются в 2×.

## Замена

1. Заменить нужный файл в source/new, сохранив имя. Для остальных объектов — source/.
2. Если viewBox, размер холста или основание изменились, скорректировать запись
   scripts/sprite-spec.json. Не подгонять размер исходника на глаз изменением игрового участка.
3. Из корня репозитория в WSL выполнить:

```sh
node scripts/export-sprites.mjs
docker compose -p vsk-pitch --env-file infra/pitch.env.example -f infra/pitch.compose.yaml build frontend
docker compose -p vsk-pitch --env-file infra/pitch.env.example -f infra/pitch.compose.yaml up -d --no-deps frontend
```

Экспорт использует Playwright/Chromium, установленные для tests/pitch-browser.
Он проверяет точные 23 ID и группы, растрирует SVG, обрезает прозрачные поля,
пересчитывает точку опоры и записывает PNG/manifest/catalog. Файлы входных SVG не меняются.
Манифест содержит хеши PNG и исходников; URL изображений получает версию по хешу.
После обновления нужен Ctrl+F5 в открытой вкладке атласа.

Backend, PostgreSQL, Redis и мир ради смены рисунков перезапускать/сбрасывать не требуется.
«Под снос» обозначается тонировкой и накладкой, без дополнительного комплекта домов.
Плоские тайлы дорог/тротуаров преобразуются в изометрическую плоскость под размеры сцены;
дома не растягиваются произвольно, их положение определяется сохранённым участком.
