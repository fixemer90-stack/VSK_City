# Дорожная карта

Реализован и функционально проверен [E01 — питч-прототип](features/E01-pitch-prototype/FEATURE.md):
самостоятельный демонстрационный срез этапов A/B с минимальной логикой.
Этапы ниже не считаются полностью закрытыми из-за наличия каркаса или демо.

| Этап | Результат | Статус |
| --- | --- | --- |
| A | Технический и визуальный PoC: связный квартал, опыт, 8 уровней домов, парковки, терминации и повторное использование участков | Частично: срез E01 работает, художественная/расширенная приёмка отдельно |
| B | Демонстрационные города с постоянными центрами, стилизованная Россия, навигация страна → город → улица, «Моя улица», приватность названий | Частично: E01 на 25 тестовых городах, центры процедурные, роли демонстрационные |
| C | Корпоративный MVP: маппинг и факты, Keycloak, Kafka, C# расчёт, PostgreSQL, роли наблюдателей, идемпотентность, согласованные снимки, пилот | Не начато |
| D | Масштабирование по измеренным нагрузкам, каталог постоянных landmarks, оптимизация детализации | Не начато |

Источники объёма: [правила](GAME-RULES.md) и раздел 14
[концепции v0.4](concept/Insurance_City_Concept_Architecture_v0.4.md).
Продуктовые решения не означают готовность к подключению реальных данных:
маппинг, поля/ключи/даты фактов, порядок обработки, интервал и точные нагрузки пока неизвестны.

Первый объём — desktop, только актуальный визуальный мир, без числового прогресса,
лидерборда, календаря и сложной очереди анимаций. Публичное признание и возможный
ежегодный ресет отложены; обязательств по их реализации сейчас нет.
Игровые районы исключены: улицы напрямую принадлежат городам, кварталы остаются
элементом планировки, каналы — областью прав. Смена канала в городе сохраняет улицу;
новая улица нужна только при переводе в другой филиал-город.
Оценки сроков и трудозатрат v0.3 исторические; новая оценка v0.4 не проводилась.
Корпоративный этап C остаётся отдельной работой; наличие питча не закрывает его требования.
