# Общие контракты

Здесь будут версионируемые описания REST API, Kafka-событий и сцен.
OpenAPI, JSON Schema и генерация клиентов пока не созданы.

До реализации согласовать идентификаторы и версии; SALE/CANCEL/CORRECTION;
идемпотентность и порядок событий; снимки и изменения сцены; допустимые подписи.
Примеры в концепции — эскизы, не утверждённый контракт.
Не публиковать реальные договоры и персональные данные в примерах.
