# Общие контракты

Здесь будут версионируемые описания REST API, Kafka-событий и сцен.
OpenAPI, JSON Schema и генерация клиентов пока не созданы.

Бизнес-факты: договор заключён / досрочно терминирован; премия не передаётся.
Реальные продукты сопоставляются игровым категориям отдельно.

До реализации согласовать поля, ключи, версии, идемпотентность, порядок,
поздние факты и исправления; снимки сцен и допустимые подписи.
Отдельный ID страхового договора не гарантирован; уникальный номер — кандидат на ключ.
Для агента ожидается номер агентского договора, но стабильность/наличие проверяются на данных.
Наличие дат заключения/терминации неизвестно; дата доставки не заменяет их автоматически.
Названия SALE/CANCEL/CORRECTION из v0.3 — эскиз, не утверждённый транспортный контракт.
Минимальной первой версии достаточно актуальных сцен и проверки версии, без changes/diff/replay API.
Без права видеть имя владельца название улицы отсутствует и в интерфейсе, и в ответе API.

Источники: [правила](../docs/GAME-RULES.md) и
[концепция v0.4](../docs/concept/Insurance_City_Concept_Architecture_v0.4.md).
Не публиковать реальные договоры и персональные данные в примерах.
